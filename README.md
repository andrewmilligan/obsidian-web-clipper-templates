_Templates for the official [Obsidian Web Clipper](https://github.com/obsidianmd/obsidian-clipper), a free browser extension that lets you highlight pages and save web content to your vault. See the [official documentation](https://help.obsidian.md/web-clipper/templates#Import+and+export+Web+Clipper+templates) for instructions to import these templates._

_Originally inspired by [kepano/clipper-templates](https://github.com/kepano/clipper-templates)._
